# Doubt-Driven Development (Local Copy)
Source: c:\Users\Fan\Documents\fanrio-auth\.agents\skills\doubt-driven-development\SKILL.md

Core Methodology:
Cross-examine non-trivial decisions with adversarial testing, stress-testing assumptions, and empirical verification. Assume the author is overconfident. Find what is wrong with the artifact. Look for:
- Unstated assumptions
- Edge cases not handled
- Hidden coupling or shared state
- Ways the contract could be violated
- Existing conventions broken
- Failure modes under unexpected input
- Verify claims empirically; never trust claims without running verification code.
